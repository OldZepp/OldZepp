#### 01 · [IceFlower — Team Task Tracker](https://github.com/plumbumdreamz-collab/IceFlower)

**Простая альтернатива Jira для команды примерно из 30 человек.** Внутренний инструмент для задач, проектов, сроков, загрузки сотрудников и обсуждения работы.

- Виджеты статистики, поиск и фильтры, визуальные индикаторы просроченных задач.
- Адаптивный интерфейс, последовательно реализованный по брендбуку.

**Стек:** `Next.js (App Router)` · `TypeScript (strict)` · `Tailwind CSS` · `shadcn/ui` · `@hello-pangea/dnd` · `NextAuth.js` · `PostgreSQL` · `Prisma` · `Vercel`

[**💻 Исходный код**](https://github.com/plumbumdreamz-collab/IceFlower) · [**🌐 Демо**](https://ice-flower-black.vercel.app/)

#### 02 · [Rosie O'Grady — Florist Business Platform](https://oldzepp.chatium.ru/salon-floristiki-2)

**Сайт премиального салона флористики в Твери + внутренний учёт заказов.** Публичная витрина, заявки, сотрудники и рабочие процессы объединены в одном продукте.

- Адаптивный фирменный дизайн, галерея работ и информация о флористах из базы данных.
- Модальная форма заявки с проверкой телефона и согласием на обработку данных.
- Учёт заказов, статусов, сроков и назначенных мастеров; подсветка просроченных заказов.
- Деморежим с **серверным** запретом изменений, включая прямые обращения к API.
- Базовые SEO-решения: семантическая разметка, метаданные, alt, lazy loading и закрытая от индексации админка.

**Стек:** `Chatium` · `TypeScript` · `Vue 3` · `TSX/JSX (SSR)` · `Tailwind CSS 3` · `Heap / RefLink` · `API routes` · `Яндекс.Карты`

[**🌐 Открыть демо**](https://oldzepp.chatium.ru/salon-floristiki-2) · *Проект разработан на платформе Chatium; публичный репозиторий не указан.*

#### 03 · Nina — AI Dental Receptionist

**ИИ-администратор VK-сообщества стоматологической клиники «Дентал Люкс» (Тверь).** Бот консультирует по услугам, ценам и организации записи, уточняет потребности и формирует заявки для сотрудников клиники. Не предназначен для медицинской диагностики.

- Интеграция с **VK Bots Long Poll API**: получение `message_new` и отправка ответов через `messages.send`.
- Генерация ответов моделью `openai/gpt-5.4-nano` через **ProxyAPI**; инструкции в `system_prompt.md` и фактическая база знаний в `knowledge_base.json`.
- История диалога, контекст дат и доступных временных окон, обработка ответов для VK.
- Защитные проверки: противодействие промпт-инъекциям, контроль повторного предложения отклонённого времени, управление секретами через `.env`.
- Формирование заявок в `bookings/*.jsonl`, уведомление владельца в VK и логирование.

**Стек:** `Python 3.14` · `requests` · `GPT-5.4-nano` · `ProxyAPI` · `VK API` · `JSON/JSONL` · `Prompt Engineering`

**Статус:** 🔒 Закрытый проект · **Публичная демоверсия готовится**. Реальные обращения и персональные данные клиентов не публикуются.

**Другие направления:** сайты-визитки для экспертов и малого бизнеса, решения для A/B-тестирования, трекеры привычек, веб-калькуляторы и VK-боты.
